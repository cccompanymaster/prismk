# 🎱 구슬 룰렛 (Marble Roulette)

이름을 넣으면 구슬이 되어 장애물 코스를 달리는 **물리 시뮬레이션 추첨 게임**입니다.
구슬 레이스 방식의 랜덤 추첨 컨셉을 자체 구현했으며, **참가자 얼굴 사진을 구슬에
표시하는 기능**이 추가되어 있습니다.

## 기능

- **참가자 입력** — 줄바꿈/쉼표 구분. `이름*3` 문법으로 구슬 수(가중치) 지정
- **얼굴 사진 업로드** — 참가자별 이미지 파일 선택. 구슬 위에 원형으로 클리핑되어
  회전하며 굴러갑니다. 당첨 화면에도 크게 표시됩니다.
  이미지는 브라우저 메모리(`blob:` URL)에서만 사용되며 서버로 전송되지 않습니다.
- **물리 코스** — 지그재그 경사로 → 못(peg) 필드 → 회전 십자 장애물 → 깔때기 → 결승선
- **당첨 기준 선택** — 1등 당첨 / 꼴찌 당첨
- **카메라 추적** — 선두 구슬을 부드럽게 따라가는 카메라 + 우측 전체 진행률 바
- **정체 방지** — 코스 중간에 멈춘 구슬에 주기적으로 미세한 힘을 가해 경주가 끝까지 진행

## 실행

```bash
pnpm install
pnpm dev        # http://localhost:5173
```

## 빌드

```bash
pnpm build      # dist/ 에 정적 파일 생성
pnpm preview
```

정적 사이트이므로 GitHub Pages, Vercel, Netlify 등 어디에나 배포할 수 있습니다.

## 기술 스택

- [Vite](https://vitejs.dev) + TypeScript
- [matter-js](https://brm.io/matter-js/) — 2D 물리 엔진
- Canvas 2D 렌더링 (외부 렌더러 없이 직접 그리기)

## 구조

```
index.html          # 레이아웃 (사이드바 + 캔버스 + 당첨 오버레이)
src/
├── main.ts         # UI 바인딩, 참가자 목록, 이미지 업로드
├── game.ts         # 물리 월드, 코스 생성, 카메라, 렌더링, 당첨 판정
├── parse.ts        # 이름 파싱 (가중치 문법), 컬러 팔레트
└── style.css       # 다크 테마 스타일
```
